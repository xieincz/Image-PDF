PDF 转为图片 PDF

把每一页按 600 dpi（或更高）渲染成高清图片再组装成新的 PDF，相当于「逐页导出高清图后重新合成」。

完全在本地运行：文件只在你自己的浏览器里处理，不上传、不联网、不经过任何服务器。

      说明

      • 页面尺寸不变。输出 PDF 的每页尺寸与原 PDF 的页面尺寸（点）一致，改变的是页面内图片的像素密度。
      • 处理链路。pdf.js 逐页渲染到画布 → 编码成 JPEG/PNG → pdf-lib 把图片原样嵌入新 PDF（JPEG 直接嵌入，不二次压缩）。
      • 浏览器上限。单个画布有尺寸上限（各浏览器不同，通常单边 ≤ 16384 px）。超限时会自动降级到该页可用的最高 DPI，并在日志里提示。
      • 内存占用。转换是逐页进行的，一页处理完就释放画布；页数很多时依然建议用桌面浏览器。
      • 隐私。页面只加载同源的 pdf.js / pdf-lib 脚本，没有任何网络请求上传你的文件。

      纯静态页面，可直接部署在 GitHub Pages / 任意静态托管上。
